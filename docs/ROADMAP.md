# Gold Miner build roadmap

1. Source inventory: county courts, trustees, sheriffs, treasurers, state unclaimed-property portals.
2. Jurisdiction-specific rules registry with verified primary sources and review dates.
3. Read-only import adapters and provenance-preserving deduplication.
4. Evidence and lien/priority review queue.
5. Economics: recoverable amount estimates, costs, fee caps, and uncertainty.
6. Human-approved outreach and case preparation, only after compliance review.
7. Dashboard and integration with Full Monty AI Core.

No live collection or eligibility verification is implemented yet.
